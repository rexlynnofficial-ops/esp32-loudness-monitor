# ESP32 Loudness Monitor

Desktop hardware loudness meter (LUFS) on a Waveshare ESP32-S3 Touch LCD 3.5, with a macOS Core Audio helper, a Windows WASAPI prototype, a versioned USB protocol and host-side unit tests.

**All source code and docs are in [`esp32-loudness-monitor/`](esp32-loudness-monitor/)** — start with its [README](esp32-loudness-monitor/README.md), [SPEC](esp32-loudness-monitor/SPEC.md) and [validation notes](esp32-loudness-monitor/docs/VALIDATION.md).
